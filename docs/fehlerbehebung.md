# Fehlerbehebung

| Problem | Mögliche Ursache und Lösung |
|---|---|
| Klicks landen daneben | Kalibrierung neu durchführen, besonders nach Änderung von Auflösung oder Windows-Skalierung |
| Oberfläche verschoben | Windows-Skalierung über 100 Prozent: aktuelle Version verwenden (Korrektur seit 2.5) |
| Programm startet nicht | Nur über den Launcher starten. Lizenz und Internetverbindung prüfen |
| „Lizenz ungültig“ | Online-Prüfung fehlgeschlagen oder Freischaltung widerrufen. Ohne Internet gilt eine Frist von 48 Stunden |
| Preise fehlen | SAT-Ordner in den Einstellungen prüfen. Preise kommen aus Market.json oder dem Data Project |
| Statistik leer | Datei `stats_archive.csv` und die Läufe-Dateien prüfen, gegebenenfalls Import aus einem Export |
| Umhänge werden nicht gefunden | Scrollleiste im Umhänge-Feld neu kalibrieren |
| Nachtwache liest Zahlen falsch | Die drei Nachtwache-Kalibrierschritte wiederholen, Windows-OCR-Sprachpaket prüfen |
| Spiel reagiert nicht | Fenster muss im Vordergrund sein, Start-Verzögerung in den Einstellungen erhöhen |
